GARBA NIGHTS 2026 - Virtual Pass Creator

Files:
- index.html: main page
- style.css: design and responsive layout
- script.js: ticket updates, countdown and print button

GitHub Pages:
1. Upload all three files (index.html, style.css, script.js) to the root of a public GitHub repository.
2. Commit changes.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait a few minutes and open the Pages URL shown by GitHub.

Note: The barcode is decorative and this is a demo pass, not a verified ticket.
